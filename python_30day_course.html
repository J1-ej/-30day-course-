Цикл while, break, continue
✓
▶

while работает, пока условие истинно. while True — бесконечный цикл (основа серверов). break — немедленный выход. continue — пропустить текущую итерацию.

import random secret = random.randint(1, 100) attempts = 0 while True: guess = int(input("Угадай число (1-100): ")) attempts += 1 if guess == secret: print(f"🎉 Угадал за {attempts} попыток!") break elif guess < secret: print("📈 Больше") else: print("📉 Меньше")

class Car: # Атрибуты класса (общие для всех машин) wheels = 4 def __init__(self, brand, model, year): # Атрибуты объекта (свои у каждой машины) self.brand = brand self.model = model self.year = year my_car = Car("Toyota", "Camry", 2023) print(my_car.brand) # → Toyota print(Car.wheels) # → 4

✓

class Student: def __init__(self, name: str, grades: list): if not name: raise ValueError("Имя не может быть пустым") self.name = name self.grades = grades self.is_active = True def average(self): if not self.grades: return 0 return round(sum(self.grades) / len(self.grades), 2) s = Student("Алишер", [85, 92, 78, 95]) print(f"Средний балл: {s.average()}") # → 87.5

✓

Методы — функции внутри класса, они работают с данными объекта. Метод всегда принимает self первым. Могут вызывать другие методы через self.method().

class BankAccount: def __init__(self, owner): self.owner = owner self.balance = 0 self.history = [] def deposit(self, amount): self.balance += amount self.history.append(f"+{amount}") def withdraw(self, amount): if self._has_funds(amount): # вызов другого метода self.balance -= amount self.history.append(f"-{amount}") def _has_funds(self, amount): # _ = внутренний метод return self.balance >= amount

18
Наследование (Inheritance)
✓
▶

Дочерний класс наследует все атрибуты и методы родителя. super() вызывает родительский метод. Можно переопределять методы (override).

class User: def __init__(self, username, email): self.username = username self.email = email self.is_active = True def login(self): print(f"✅ {self.username} вошёл") class Admin(User): # Admin наследует User def __init__(self, username, email, level): super().__init__(username, email) # вызов родителя self.level = level def delete_user(self, user): print(f"🗑 {self.username} удалил {user.username}")
Задача дня

Иерархия: User → Admin → SuperAdmin. Каждый уровень добавляет новые методы и атрибуты. SuperAdmin может менять уровень Admin.

Инкапсуляция — скрытие данных
✓
▶

Приватные атрибуты __attr нельзя изменить снаружи напрямую. Доступ только через методы (геттеры и сеттеры). Это фундамент безопасности данных.

class SecureAccount: def __init__(self, owner, password): self.owner = owner self.__balance = 0 # приватный! self.__password = password # приватный! def get_balance(self, password): if password == self.__password: return self.__balance return "❌ Неверный пароль" # Попытка взломать снаружи: acc = SecureAccount("Алишер", "qwerty") # acc.__balance = 99999 → AttributeError!
🔒 Связь с безопасностью

Инкапсуляция — это не только красивый код. В реальных системах так защищают пароли, ключи шифрования и финансовые данные от случайного изменения.

Магические методы __str__, __repr__
✓
▶

class User: def __init__(self, name, role): self.name = name self.role = role def __str__(self): # Вызывается при print(user) return f"👤 {self.name} [{self.role}]" def __repr__(self): # Вызывается в отладке return f"User(name={self.name!r}, role={self.role!r})" def __eq__(self, other): return self.name == other.name u = User("Алишер", "admin") print(u) # → 👤 Алишер [admin]

Хеширование паролей — hashlib
✓
▶

Хеш — одностороннее преобразование. Нельзя восстановить исходные данные из хеша. SHA-256 — стандарт. «Соль» (salt) — случайные данные для защиты от радужных таблиц.

import hashlib import os def hash_password(password: str) -> str: # Соль — случайные байты, делает хеш уникальным salt = os.urandom(32) key = hashlib.pbkdf2_hmac( "sha256", password.encode(), salt, 100000 ) return salt.hex() + key.hex() def check_password(password: str, stored: str) -> bool: salt = bytes.fromhex(stored[:64]) stored_key = stored[64:] key = hashlib.pbkdf2_hmac("sha256", password.encode(), salt, 100000) return key.hex() == stored_key
🔒 ВАЖНО

В реальных проектах используй библиотеку bcrypt или passlib — они специально спроектированы для паролей и умеют регулировать сложность хеширования.

Задача дня

Многопоточность — threading
✓
▶

Поток — параллельная задача внутри программы. Полезно для сетевых операций, I/O задач. ThreadPoolExecutor — удобный способ создать пул потоков.

import socket from concurrent.futures import ThreadPoolExecutor def scan_port(host, port): try: sock = socket.socket() sock.settimeout(0.5) result = sock.connect_ex((host, port)) sock.close() if result == 0: print(f"✅ Порт {port} открыт") except: pass host = "127.0.0.1" ports = range(1, 1025) # Сканируем 100 портов одновременно with ThreadPoolExecutor(max_workers=100) as pool: pool.map(lambda p: scan_port(host, p), ports)
⚠ Правило

Сканируй порты только на своих системах или с явного разрешения. Сканирование чужих серверов без разрешения — это незаконно.

Задача дня
